# Wooden road-sign assets

- `EBGaramond12-Bold.ttf`: EB Garamond 12 Bold, version 0.016, Georg A.
  Duffner. Unmodified copy of the installed font from
  `/usr/share/fonts/truetype/ebgaramond/EBGaramond12-Bold.ttf`.
  Copyright and SIL Open Font License 1.1 are reproduced from the font's own
  name-table license record in `OFL.txt`. The renderer retains its existing
  fallback fonts for symbols missing from this face.
- `oak.png`: generated with the built-in image-generation tool on 23 October
  2026 for this project (1254×1254 PNG output). Runtime downsamples it to a cached512px sRGB texture
  with mipmaps; no image generation or decoding occurs in movement frames.

## Wood generation prompt

Create a square, seamlessly tileable photorealistic oak wood base-color texture
for wooden road signs in a realistic 3D game. Straight-on orthographic scanned
surface filling the whole image, evenly lit, no perspective, no baked directional
lighting or shadows. Warm light-to-medium weathered honey-tan oak, not orange,
suitable for high-contrast black painted letters to be added later in the
renderer. Horizontal flowing wood grain, believable fine pores and subtle small
knots, a few horizontal tightly joined plank seams with each plank about a
quarter of the tile height. Natural restrained variation without heavily dark
stains or distracting cracks. Perfectly repeatable edges in both directions.
No text, lettering, symbols, nails, metal, border, frame, vignette or objects.
Material albedo only, crisp high-resolution grain,1024 by1024 square.
