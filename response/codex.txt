I checked the newest manual run `test-runs/manual/1785679238-738888`.

The large dark/grey rectangular holes were a real shader bug, not fog or missing terrain: the
near-field test treated normal 131x131 tile textures as the 1025x1025 near-field texture, so it
used 1024-quad coordinates on them and read invalid texels at high altitude.

Fixed with an exact 1025-width check. Validation replay `test-runs/orbit_once/1785679670-742426`
shows an intact planet with the holes gone. The orange stippled oval still visible in one frame is
a separate LOD transition/dither artifact, not the rectangular-hole fault.

I’m running the full format/tests now, then I’ll commit and push this fix before starting step 4.
