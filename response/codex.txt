Yes, it could cause trouble, but there is no fundamental precision or planet-size limit stopping us.

The important detail is that terrain is currently **1× below 100km**, then blends to **4× by 1,000km**. Therefore:

- A fixed global **3×** would triple low-flight terrain, but orbital relief would actually fall from the current 4× to 3×.
- Multiplying the existing profile by three would become **3× near / 12× far**. I would not do that: the new planet's 8,846m peak would reach about **106km** at orbit.

A fixed 3× experiment would make the highest terrain about **26.5km ASL**. The engine can represent that safely, and the 720km atmosphere still contains it, provided every path uses the same transform. Expected consequences:

1. **Camera/scenario heights:** the new sparse landing ground would move from roughly 1,011m to 3,034m. Ground scenarios and any fixed world-space camera paths would need re-authoring.
2. **Raster/ray/CPU agreement:** the raster shader, ray shell/hit logic, CPU clearance, probes, culling and LOD bounds must all change together. A shader-only multiplier would put the camera and ray renderer on a different surface.
3. **ASL versus bathymetry:** the current shared scale multiplies signed baked heights, so simply changing its constant would also deepen the ocean floor. For true “altitude ASL only,” we should scale positive heights and leave sea level/bathymetry unchanged.
4. **Visual quality:** the globally dense source is still L4, about 3.9km between samples. Tripling vertical relief will make coarse facets, steep coastline walls and angular distant mountains roughly three times more obvious. Snow/rock material weighting and atmospheric lighting will also shift strongly.
5. **Performance:** larger height bounds and steeper terrain can increase conservative visibility and LOD demand, putting more pressure on the 256-chunk budget.
6. **Climate remains baked:** deserts, forests, rivers and snow-biome ownership would still reflect the original elevations unless we rebake climate too.

**Recommendation:** try a runtime, positive-height-only **fixed 3×** first—do not rebake and do not stack it on the existing 4× orbit boost. Then rerun `orbit_once`, `stand_on_ground`, low flight, mountains and raster/ray parity. It is a manageable experiment, but I would expect dramatic mountains plus noticeably worse global-L4 faceting.
