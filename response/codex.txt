Checked the newest screenshots: capture-003/004 show steep mountain faces collapsing to near-black while sun-facing snow is bright. The cause was sky_diffuse_irradiance sampling only the terrain normal, which returns zero for back-facing facets even in daylight.

Fixed with a bounded zenith-sky ambient contribution (35% before the existing cap). It is shared by flat and ordinary terrain/ocean lighting, remains zero when the night-side sky is zero, and does not create moonless emission.

Validation: 48 terrain tests passed; app cargo check and git diff --check passed. Changes are ready to commit/push after final status check; a fresh daylight GPU capture is still needed to tune visual strength.
