## Diagnosis

The handoff attributed the missing labels to nearest-neighbour resampling. The actual
failure is **after sampling**: starting at L3, `baked_biome_detail` converts high-altitude
labels back to Ice. Parent-border constraints preserve a few labels from L2, creating the
appearance of severe decimation.

| Level | Old moraine, all stored samples | Old crevasse, all stored samples | Old moraine/crevasse in interiors |
|---|---:|---:|---:|
| L0 | 115 | 1,553 | 103 / 1,446 |
| L1 | 383 | 6,310 | 364 / 5,952 |
| L2 | 1,615 | 25,298 | 1,526 / 23,791 |
| L3 | 180 | 2,810 | 0 / 0 |
| L4 | 368 | 5,642 | 0 / 0 |

The new `exported_tiles_preserve_classified_glacier_structure` regression constructs ice,
moraine and crevasse fields above the snowline, calls `sample_tile` and parent-border
constraints at L2/L3/L4/L18. Before the fix it fails at moraine L3; afterwards it passes.
A classifier regression checks clean flat ice, slope-triggered crevasses, debris precedence
where flow converges, and exclusion of polar sheets.

## Next step

The data-loss blocker is fixed. Do not widen classifier thresholds or dilate the working
grid on the assumption that export still loses the labels. Next trace restored labelled
regions through material/lighting/final pixels, then implement actual glacier-scale
appearance/structure rather than expecting a different biome palette to create cracks.
Keep the judging camera and references fixed. Any renderer change still requires matched
frame-time evidence; use independent Luna judges only once a visible improvement exists.
